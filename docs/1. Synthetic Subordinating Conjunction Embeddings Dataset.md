## 2. Conjunction Bug Remediation Methodology

During synthetic sample generation (Notebook 3), subordinating conjunction connectives (e.g., *if*, *because*, *although*, *provided that*, *unless*) were structurally embedded inside either `premise_1` or `premise_2`.

To support clean representation learning and vector space geometry research:
1. **Detection & Extraction:** The pipeline programmatically checks which raw premise contains the subordinating conjunction.
2. **Conjunction Stripping:** The conjunction string is stripped from the premise text using regular expression pattern matching at word boundaries, trimming leading/trailing commas and whitespace, and restoring standard upper/lower sentence capitalization.
3. **Four Target Text Variations:** Each sample is prepared with four distinct textual components:
   - `premise_1_clean`: Isolated Premise 1 proposition strictly without the subordinating conjunction.
   - `premise_2_clean`: Isolated Premise 2 proposition strictly without the subordinating conjunction.
   - `premise_with_conjunction`: The specific original premise fragment containing the subordinating conjunction.
   - `constructed_sentence`: The full reconstructed complex sentence containing both premises and the subordinating conjunction connective.

## 3. Dataset Schema & Column Definitions

### Unembedded Cleaned Schema (`synthetic_subordinating_conjunction_sentences_cleaned`)

| Column Name | Data Type | Description |
| :--- | :--- | :--- |
| `prompt_name` | `string` | The parent PERSUADE 2.0 essay prompt topic (e.g., *Car-free cities*, *Exploring Venus*). |
| `conjunction` | `string` | The subordinating conjunction operator (e.g., *because*, *if*, *although*). |
| `conjunction_type` | `string` | Subordinating conjunction functional class (`conditional`, `causal`, `concession`). |
| `premise_1_raw` | `string` | Uncleaned raw Premise 1 text excerpt. |
| `premise_2_raw` | `string` | Uncleaned raw Premise 2 text excerpt. |
| `premise_1_clean` | `string` | Cleaned Premise 1 proposition strictly without the conjunction. |
| `premise_2_clean` | `string` | Cleaned Premise 2 proposition strictly without the conjunction. |
| `premise_with_conjunction` | `string` | Original premise fragment containing the subordinating conjunction. |
| `constructed_sentence` | `string` | Reconstructed full complex sentence containing both premises and connective. |

### Quad-Embedded Schema Additions (`synthetic_subordinating_conjunction_sentences_with_embeddings`)

| Column Name | Data Type | Dimensions | Description |
| :--- | :--- | :--- | :--- |
| `premise_1_clean_embedding` | `list[float]` | 384 | Dense vector representation of `premise_1_clean`. |
| `premise_2_clean_embedding` | `list[float]` | 384 | Dense vector representation of `premise_2_clean`. |
| `premise_with_conjunction_embedding` | `list[float]` | 384 | Dense vector representation of `premise_with_conjunction`. |
| `full_sentence_embedding` | `list[float]` | 384 | Dense vector representation of `constructed_sentence`. |
